# Data-Analytics.Visualizations

--SQL--
Developed SQL queries against a relational HR database to practice joins, CTEs, window functions, ranking, and hierarchical relationships. Documented query objectives and methodology throughout the project.

I worked with AI (ChatGPT, free version) to instruct me to create specified queries on demand in each aspect where I felt I needed much practice.

--IBM Cognos Analytics--
IBM Cognos Analytics dashboard as a PDF due to ability to only share the proper dashboard within the same 'Team' on IBM's platform.
This dashboard was created based on survey data from users on the annual StackOverflow.com Developer Survey.
From StackOverflow... "Every year we ask developers about the tools they use, how they learn, and how they work."

--Tableau--
I analyzed a dataset from cdc.gov concerning US chronic illnesses gathered in 2023.  I focused on data that would concern CVS Health and its subsidiaries, CVS Pharmacy and Aetna.
