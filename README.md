# HR-Data-Analysis
Developed SQL queries against a relational HR database to practice joins, CTEs, window functions, ranking, and hierarchical relationships. Documented query objectives and methodology throughout the project.

I worked with AI (ChatGPT, free version) to have me create specified queries on demand in each aspect where I felt I needed much practice.

'Self Joins' is based on a slightly modified dataset from the others, as it took a unique use case to necessitate, and practically accommodate, self joins.
